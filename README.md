# 감자도 취업한다

춘천 대학생·취업 준비생의 직업 탐색과 개인별 커리어맵 서비스. 기존 정적 HTML/Vercel 구조를 유지하며 의존성 없이 실행합니다.

## 실행·검증

- `npm start` 후 http://localhost:3000 접속 (Python 3 필요)
- `npm test` (Node.js 20 이상)
- Vercel: 프레임워크 Other, 빌드 명령 없음, 출력 디렉터리 저장소 루트

## 구성

- `index.html`, `styles.css`: 접근 가능한 화면 틀과 반응형 스타일
- `app.js`: 화면, 자동 저장, 관심 직업, 직업별 역량·계획 CRUD/순서 변경/비교
- `logic.js`: 설명 가능한 추천, 개인 일정, 경험별 활동 생성, 감자 상태
- `data.js`: 기존 20개 직업을 확장한 구조화 데이터와 공식 탐색 출처

개인 정보·직업별 계획은 `potatoCareer.v2` localStorage에 저장됩니다. 기존 `careerProfile`, `careerSavedJobs`, `careerLastActivity`는 최초 실행 시 가져옵니다. 기존 저장 키를 삭제하지 않으며 이전 게임 지도 계획은 형식과 의미가 달라 자동 변환하지 않습니다. 브라우저 삭제나 기기 변경 시 데이터가 유지되지 않습니다.

추천은 전공(3), 관심·경험·도구와 직무/역량의 텍스트 일치(각 2), 일부 가치/지역/근무 형태(각 1)를 사용하며 점수는 UI에 적합도로 노출하지 않습니다. 연봉·외국어·대학원 의향은 저장하지만 검증된 직무 데이터가 없어 순위에 반영하지 않습니다. 안정성·워라밸 등은 공고별 확인이 필요합니다. 역량 상태 변경 시 부족 역량/추천 활동이 즉시 변경됩니다. 기존 계획은 보존하며 추천 활동 추가와 일정 재배치는 사용자가 실행합니다. 일정은 월 단위, 졸업까지 최대 24개월로 배치합니다.

지역 정보는 기관 탐색 출처이며 실시간 채용 연동이 아닙니다. 모집 여부와 확인 날짜는 미확인으로 표시합니다. 링크·기관 정보는 운영 전에 주기적으로 검증해야 합니다. 직업 정보는 일반적인 탐색용 자료로 개별 고용주의 요건을 대체하지 않습니다.

## 감자 이미지 교체

이미지를 생성하지 않았습니다. `assets/mascot/fresh.svg`, `worried.svg`, `wilted.svg`, `rotten.svg` 파일을 추가하면 상태에 맞게 표시됩니다. 파일이 없으면 이미지 준비 중 영역을 표시합니다. 마지막 유효 활동 이후 0–2/3–6/7–13/14일 이상에 따라 상태가 바뀌며 단순 방문은 상태를 회복시키지 않습니다.

## 수동 확인

진단 저장 → 직업 검색/상세/관심 저장 → 목표 설정 → 역량 상태·기록 편집 → 추천 활동 추가 → 계획 내용/기간/상태/결과/증빙 편집 → 순서 변경·삭제 → 다른 직업 목표 설정 → 비교 → 새로고침 후 보존 → 지역 필터/공식 링크를 확인합니다. 화면은 600px 이하 한 열로 표시합니다.
